# Post-processing

The existing selective bloom and the filmic grade share one full-screen pass. Bloom still only extracts the brightest reflective grains; the grade then adds a restrained contrast curve, slight shadow/highlight color separation, a small saturation reduction, and a subtle vignette.

The grade is intentionally mild so the sand material remains physically readable. It should feel a little moodier and more photographic without crushing the dark grains, clipping the sun glints, or adding another render pass.
